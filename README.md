# Combinado

Protótipo navegável do Combinado, um app para o grupo de amigos fechar data, orçamento e casa da viagem sem ninguém expor quanto pode gastar e sem ninguém precisar cobrar ninguém.

**Abrir o protótipo:** https://luccapacios.github.io/combinado/

## O que dá para fazer

- Entrar pelo convite da Ju, sem cadastro, ou criar uma conta com celular e código por SMS (na demonstração, o código é 482 915).
- Decidir a viagem Praia em novembro em quatro etapas: datas com prazo, teto de gasto em segredo, votação só entre casas dentro da faixa e confirmação com sinal.
- Ver o recibo do que ficou combinado, a lista do que levar e o resumo pronto para o grupo do WhatsApp.
- Acompanhar a atividade, o cofre da viagem e o grupo, e sair da viagem.
- Criar uma viagem nova em quatro passos.
- Editar o perfil, a chave Pix, as notificações e a privacidade, baixar os próprios dados, sair e apagar a conta.

Os dados são de uma viagem de exemplo e ficam só no navegador. Os prazos fecham por um botão de demonstração, e nenhum pagamento é real.

Projeto em UX Design, Pós-graduação em User Experience, Senac São Paulo.
