# Combinado

Protótipo navegável do Combinado, um app para o grupo de amigos fechar data, orçamento e casa da viagem sem ninguém expor quanto pode gastar e sem ninguém precisar cobrar ninguém.

**Abrir o protótipo:** https://luccapacios.github.io/combinado/

Projeto em UX Design, Pós-graduação em User Experience, Senac São Paulo.
Julyana Morais e Lucca Pacios, 2026.

Os dados são de uma viagem de exemplo. Os prazos fecham por um botão de demonstração, e nenhum pagamento é real.
